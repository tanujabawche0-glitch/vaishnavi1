# BEYOND BINARY — Autonomous Competitive Intelligence Agent

> **Tagline:** Discover • Analyze • Predict • Act  
> **Team:** Beyond Binary  
> **Built for:** National Level Hackathon Competition

---

## Executive Summary

Organizations face massive operational drag trying to manually track scientific papers, patent registries, competitor activities, and industry news. **Beyond Binary** is a full-stack, multi-agent AI system that continuously crawls, normalizes, synthesizes, and alerts executive teams to critical competitive shifts.

---

## Tech Stack Architecture

- **Frontend:** React 18, Vite, Tailwind CSS, Recharts, Lucide React
- **Backend Services:** Supabase Edge Functions (TypeScript/Deno)
- **Database & Security:** Supabase PostgreSQL with strict Row Level Security (RLS)
- **Authentication:** Supabase Auth (JWT + Session Persistence)
- **Deployment:** Vercel + Supabase Cloud
